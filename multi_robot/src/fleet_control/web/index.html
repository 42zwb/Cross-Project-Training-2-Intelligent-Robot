首次任务前调整分区（m）

每行 xmin、ymin、xmax、ymax。三个矩形须覆盖 15×15 m 场地、不重叠且包含各自起点。首次运动任务后锁定；探索受分区阻挡时自动解除边界。

航点巡逻

仅在所属分区的已观测安全空闲区运行。每个航点为 [x, y, yaw]；可为一台或多台车指定路线。暂停后重新提交会从第一点开始。
